# Redaifu V4.1 assets

- `site.css`: 全ページ共通のレスポンシブスタイル
- `site.js`: モバイルメニュー、1回限りの演出、メールアプリ用フォームとコピー補助
- `*.webp`: 承認デザインを参考にImageGenで制作したイメージ写真。実在店舗・制作実績の写真としては表示しない
- `icons/*.svg`: Phosphor Icons Core 2.1.1 / MIT。ライセンスは `icons/LICENSE.txt`
- `serif-jp.woff2`: Noto Serif JP / SIL Open Font License。ライセンスは `NotoSerifJP-OFL.txt`。現在の文面の文字を含むサブセット。本文はOSの日本語フォント
- 実際の制作実績・運営者写真・ロゴは従来の `assets/images/` を参照

外部スクリプト、トラッキング、顧客情報の永続保存は追加していません。メールフォームはWebサイトから直接メールを送信するものではなく、利用者のメールアプリを開きます。
